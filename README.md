# 💰 Expense Tracker

A simple Expense Tracker built with HTML, CSS, and JavaScript.

## Features

- Add Income
- Add Expenses
- Calculate Balance
- Delete Transactions
- Save Data with localStorage
- Responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript
